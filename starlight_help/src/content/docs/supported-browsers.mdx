Grow Team works in all major modern web browsers. We recommend
pinning the Grow Team tab in your favorite browser, so that it's always
easy to find.

For the best user experience, the latest stable versions of the
browsers below are recommended.

* [Chrome](https://www.google.com/chrome/)
* [Firefox](https://mozilla.org/en-US/firefox/browsers/)
* [Edge](https://microsoft.com/en-us/edge/)
* [Safari](https://apple.com/safari/)

## Support policy

The Grow Team web app guarantees support for all versions of the major browser
engines (Chrome, Firefox, Safari, and Edge) that are sufficiently recent to
support the Web Platform Baseline "widely available" category. Users using
versions of these browsers that are several years old and do not support
the widely available Web Platform Baseline features will receive an in-app
warning encouraging them to upgrade.

## Multi protocol chat apps

Grow Team can work with browser-based multi protocol desktop chat apps such as
[Rambox](https://rambox.pro) and [Ferdium](https://ferdium.org/).

<ZulipTip>
  Choose an app that releases regular security updates. Running
  an out-of-date app is a major security risk for your computer.
</ZulipTip>
