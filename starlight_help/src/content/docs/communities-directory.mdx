---
title: Upstream communities directory
---

The [Zulip communities directory](https://zulip.com/communities/) belongs to the upstream project.
Grow Team does not operate this directory or offer a sponsorship program.

Grow Team is intended for private team collaboration. Ask your organization's administrator before making channels or membership public.

For information about the external directory, use the [upstream directory documentation](https://zulip.com/help/communities-directory).
