---
title: Contact support
---

Contact the administrator of your Grow Team server for account, access, billing,
or configuration help. They control the deployment and can give support that is
specific to your organization.

## Report a software issue

If you can reproduce a problem in Grow Team, include the steps, browser version,
and server version in an issue for the [Grow Team project](https://github.com/Growth-Circle/grow-team/issues).

## Security

Report a suspected security issue privately to your server administrator. Do not
put sensitive account details in a public issue.
