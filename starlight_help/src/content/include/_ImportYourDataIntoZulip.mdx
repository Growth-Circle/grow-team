To start using Zulip, you will need to choose between Zulip Cloud and
self-hosting Grow Team. For a simple managed solution, with no setup or
maintenance overhead, you can [sign up](https://zulip.com/new/) for
[Zulip Cloud](https://zulip.com/zulip-cloud) with just a few clicks.
Alternatively, you can [self-host](https://zulip.com/self-hosting/)
your Grow Team organization. See [here](/help/zulip-cloud-or-self-hosting)
to learn more.

<ZulipNote>
  **You can only import a workspace as a new Grow Team organization.** Your imported
  message history cannot be added into an existing Grow Team organization.
</ZulipNote>
