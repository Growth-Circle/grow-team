**Feature level ZF-492662**

* [`GET /playbooks`](/api/list-playbooks),
  [`POST /playbooks`](/api/create-playbook),
  [`GET /playbooks/{playbook_id}`](/api/get-playbook),
  [`PATCH /playbooks/{playbook_id}`](/api/update-playbook),
  [`POST /playbooks/{playbook_id}/archive`](/api/archive-playbook),
  [`POST /playbooks/{playbook_id}/unarchive`](/api/unarchive-playbook),
  [`GET /playbooks/{playbook_id}/revisions/{revision_number}`](/api/get-playbook-revision),
  [`GET /playbooks/{playbook_id}/diff`](/api/get-playbook-diff): New
  endpoints for playbooks, Markdown documents that describe how the team
  does a piece of work. A shared playbook is for every member except a
  guest; a personal playbook is for its owner alone. Every edit adds a
  revision, and an edit made from an outdated `base_revision` fails with
  the `PLAYBOOK_REVISION_CONFLICT` error code and HTTP status 409. The
  stable `id` of a playbook, and the `content` of its latest revision, are
  what an agent integration reads.
* [`GET /events`](/api/get-events): New `playbook` events report playbooks
  that are added, edited, or archived. A shared playbook's events reach
  every active non-guest user; a personal playbook's reach its owner.
