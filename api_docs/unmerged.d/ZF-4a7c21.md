**Feature level ZF-4a7c21**

* [`GET /tasks`](/api/get-task-board), [`POST /tasks`](/api/create-task),
  [`GET /tasks/counts`](/api/get-task-counts),
  [`PATCH /tasks/{task_id}`](/api/update-task),
  [`DELETE /tasks/{task_id}`](/api/delete-task),
  [`GET /tasks/{task_id}/history`](/api/get-task-history),
  [`PATCH /task_boards/{board_id}`](/api/update-task-board): New Grow Team task
  board APIs read a board, create cards, move and edit cards, read a card's
  history, read the Work group totals, and rename a board. A card can name a
  reviewer, and a column can be marked as a review column. A card keeps a reference to the conversation it
  came from and inherits that channel's access. Moving a card never changes the
  conversation.
* [`GET /events`](/api/get-events): New `task` events report cards that are
  added, updated, or removed. New `task_board` events report a renamed board.
  Both reach only the users who may read the card's origin channel. Neither
  event carries [`POST /register`](/api/register-queue) state; a client fetches
  the board when it opens one.
