**Feature level ZF-e3d428**

* Added `GET /needs`, which lists agent approvals and agent decisions
  waiting on the caller, and personal mentions and 1:1 direct messages
  the caller has not answered, with a count per kind. A personal mention
  is listed while it is unread, and again once two hours pass without a
  reply from the caller in its conversation. A message in a 1:1 direct
  message follows the same rule, with no mention required. Each item
  carries the arguments that the approval and input endpoints need, and,
  under `status=resolved`, when and how the caller handled it.
* Added `POST /needs/mentions/{message_id}/resolve` and
  `DELETE /needs/mentions/{message_id}/resolve`, which mark a personal
  mention, or a message in a 1:1 direct message, done in the list above,
  and undo that.
* Agent approvals now expire after the workspace's own
  `approval_ttl_minutes` setting instead of a fixed 15 minutes, or when
  the task's own time budget runs out, if that comes first.
* `POST /agent/approvals/{approval_id}/decision` now rejects a user
  without the approve permission, such as a Guest.
