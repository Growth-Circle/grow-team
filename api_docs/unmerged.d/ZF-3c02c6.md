**Feature level ZF-3c02c6**

* [`GET/PATCH /json/agent/realm-settings`](/api/get-workspace-realm-settings):
  New endpoint. Reads and changes the workspace's Sanji settings (time
  zone, agent language, default runner and model provider, invitation
  and budget limits), and reports which optional integrations this
  server has configured.
* [`GET/PUT /json/realm/permissions`](/api/get-workspace-permissions):
  New endpoint. Reads and changes the workspace's role permission
  matrix.
* [`GET /json/realm/audit`](/api/get-workspace-audit),
  [`GET /json/realm/audit.csv`](/api/export-workspace-audit-csv): New
  endpoints. Read the workspace's audit log, as JSON or as a CSV file.
* [`GET /json/users/me/workspaces`](/api/list-my-workspaces): New
  endpoint. Lists every workspace on this server the requester's email
  belongs to.
