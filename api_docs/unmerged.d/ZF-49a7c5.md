**Feature level ZF-49a7c5**

* [`GET/PUT /mcp/access/{grant_id}/tools`](/api/get-mcp-access-tools): New
  endpoints to read and change the policy (`allow`, `approve` or `block`)
  of each tool of one of your external MCP connections.
* [`GET /mcp/audit`](/api/list-mcp-audit): New endpoint to list what
  happened to external MCP calls, without their content.
* [`POST /mcp/calls/{call_id}/decision`](/api/decide-mcp-call): New
  endpoint to approve or reject a call that an external client made to an
  Ask first tool.
* [`GET /mcp/access`](/api/list-mcp-access): Connection objects now include
  `policy_mode`.
* [`GET /needs`](/api/list-needs): An approval for such a call has an id
  that starts with `mcp_call:`, `reject` among its `actions`, and an
  `mcp_call` field with the tool, target and full content.
