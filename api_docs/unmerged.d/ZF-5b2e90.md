**Feature level ZF-5b2e90**

* [`GET /tasks/{task_id}/notes`](/api/get-task-notes),
  [`POST /tasks/{task_id}/notes`](/api/add-task-note),
  [`DELETE /tasks/{task_id}/notes/{note_id}`](/api/delete-task-note): New
  endpoints read, add, and delete the notes on a task card. A note is
  rendered with Zulip Markdown. Any user who can read a card can add a
  note; only the author or an organization administrator can delete one.
* [`GET /tasks`](/api/get-task-board), [`GET /events`](/api/get-events):
  Task objects now include a `note_count` field.
* [`GET /tasks/{task_id}/history`](/api/get-task-history): Added the
  `note_added` history kind.
* [`GET /events`](/api/get-events): New `task_note` events report notes
  that are added or removed. They reach the same users as `task` events.
