**Feature level ZF-c17a16**

* [`GET /events`](/api/get-events): Added five event types. `agent_job`
  reports a job's status, phase, and version. `agent_runner` reports a
  runner's status, and a separate `pairing` op reports a pairing's
  state. `room_meta` reports a room's due date and summary setting.
  `realm_permissions` and `agent_realm_settings` report a change to the
  workspace's permission matrix or agent settings, so a client can
  re-fetch the changed resource instead of polling it.
