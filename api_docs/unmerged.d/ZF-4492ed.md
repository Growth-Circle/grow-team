**Feature level ZF-4492ed**

* [`GET /agent/profiles/{profile_id}/status`](/api/get-agent-profile-status):
  New endpoint that returns what one agent is working on, the approvals
  and decisions that wait on you, and what you decided in the last 7 days.
  It lists only the jobs you can open, and answers for an agent you
  cannot see like an ID that does not exist.
