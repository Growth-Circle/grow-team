**Feature level ZF-988a72**

* [`GET /needs`](/api/list-needs): Each item has a new `broadcast`
  boolean. It is `true` for a `mention` or `card_mention` item whose
  message or note names 3 or more people or uses a wildcard mention such
  as `@all`, unless it names no other human than you; it is `false` for
  every other item, and for a direct message. Clients can use it to hide
  team-wide mentions by default.
