**Feature level ZF-6d2b13**

* [`GET /tasks/plan`](/api/get-task-plan),
  [`POST /tasks/{task_id}/plan`](/api/add-task-to-plan),
  [`PATCH /tasks/{task_id}/plan`](/api/reorder-task-plan),
  [`DELETE /tasks/{task_id}/plan`](/api/remove-task-from-plan): New
  endpoints read and change the user's private plan of task cards for a
  day. Any card the user can read may be planned; nobody else can read the
  plan.
* [`GET /events`](/api/get-events): New `task_plan` events report a card
  added to, moved within, or removed from the user's plan. They reach only
  the user who owns the plan.
