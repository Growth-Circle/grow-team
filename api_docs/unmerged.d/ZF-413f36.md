**Feature level ZF-413f36**

* [`GET /needs`](/api/list-needs): Each item has a new `raw_text` string.
  The `text` of a `mention` or `card_mention` item is now the first
  sentence of its message or note once the @-mentions it opens with are
  removed, so a message that begins with a list of names no longer fills
  the excerpt with them. `raw_text` is the excerpt as `text` was before.
