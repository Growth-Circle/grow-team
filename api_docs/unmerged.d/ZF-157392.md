**Feature level ZF-157392**

* [`GET /agent/jobs`](/api/list-agent-jobs), [`GET /agent/jobs/{job_id}`](/api/get-agent-job),
  [`POST /agent/jobs`](/api/create-agent-job): Job objects now include
  `result_message_id`, `step_label`, `progress`, and `artifacts` fields, so a
  client can render a job's card without a separate request. `reason_code` is
  now `runner_offline` for a queued job whose runner sent no heartbeat in the
  last 45 seconds.
* [`POST /agent/jobs`](/api/create-agent-job): A user whose role cannot give
  tasks to agents now gets an error.
* [`GET /agent/messages/{message_id}/dispatch`](/api/get-agent-message-dispatch):
  Added the `profile_paused` and `role_not_allowed` rejection reasons.
