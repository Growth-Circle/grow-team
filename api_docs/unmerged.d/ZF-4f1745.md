**Feature level ZF-4f1745**

* [`POST /agent/profiles`](/api/create-agent-profile),
  [`PATCH /agent/profiles/{profile_id}`](/api/update-agent-profile): Added
  the `agent_role`, `avatar_shape`, `avatar_color`, `model_preset`,
  `monthly_budget_microunits`, `work_skills`, and `work_tools` fields. An
  update that omits one of these fields keeps its current value.
* [`POST /agent/profiles`](/api/create-agent-profile),
  [`PATCH /agent/profiles/{profile_id}`](/api/update-agent-profile): A name
  that an active user or bot in the organization has, or a reserved name,
  now fails with the `agent_name_unavailable` error code.
* [`GET /agent/profiles`](/api/list-agent-profiles),
  [`GET /agent/profiles/{profile_id}`](/api/get-agent-profile): Profiles
  also report the fields above, a `kind` (`work` or `coding`), a
  `model_label`, and `is_builtin`.
* [`GET /agent/profiles`](/api/list-agent-profiles),
  [`GET /agent/profiles/{profile_id}`](/api/get-agent-profile): Profiles
  also report `access_grants`: the channels, Drive folders, and MCP
  connections that the agent can reach.
