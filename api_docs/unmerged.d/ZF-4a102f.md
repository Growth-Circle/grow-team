**Feature level ZF-4a102f**

* [`GET /streams/{stream_id}/pins`](/api/get-channel-pins),
  [`POST /messages/{message_id}/pin`](/api/pin-message),
  [`DELETE /messages/{message_id}/pin`](/api/unpin-message): New
  endpoints list, add, and remove the pinned messages of a channel. Anyone
  who can read the channel can list its pins; pinning and unpinning need
  permission to post in the channel.
* [`GET /events`](/api/get-events): New `channel_pin` events report a
  message being pinned or unpinned. They reach the users who can read the
  channel.
