**Feature level ZF-d81c47**

* [`POST /tasks/{task_id}/notes`](/api/add-task-note): A note that
  mentions a member now notifies them, if they can read the card. The
  response has a new `ignored_mentions` field listing mentioned users who
  were not notified because they cannot read the card.
* [`POST /tasks/{task_id}/notifications/resolve`](/api/resolve-task-notifications):
  New endpoint to mark the current user's notifications on a card as
  handled, for when they open the card.
* [`GET /needs`](/api/list-needs): New `card_mention` and `card_assigned`
  item kinds, for a task note that mentions you and for a card made yours,
  with matching counts. Items of these kinds carry a new `task` object; the
  field is `null` on every other kind.
* `POST /needs/card_notifications/{notification_id}/resolve`: New endpoint
  to mark a card item handled.
* [`GET /events`](/api/get-events): New `task_notification` events tell a
  user that a card item was added for them, or closed, so a client can
  refresh their Needs-you list. They are sent only to that user.
